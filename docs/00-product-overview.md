# 00 — Product Overview

## Product name
Working title: Fitness Event CRM

## Product vision
Build a simple web application that allows an independent fitness coach to operate fitness events across places of worship, community centers, and partner venues without relying on spreadsheets.

The system must:
1. Let participants register from a public mobile-friendly link.
2. Let participants select one or multiple event dates.
3. Enforce capacity and deadlines per event.
4. Maintain one persistent participant identity across all venues.
5. Record attendance and participant history.
6. distinguish first time with the coach from first time at a host organization.
7. Give host administrators access only to events at their assigned institutions.
8. Create lightweight follow-up tasks with copyable suggested messages.
9. Offer Google Calendar links and downloadable iCalendar files.

## Operational problem
Today, event registration, attendance, organization affiliation, participant history, and follow-up can become fragmented across forms, spreadsheets, messages, and memory. The application creates one reliable workflow and one source of truth.

## Core product loop
Create Event → Share Link → Register → Check In → Finalize Attendance → Update History → Create Follow-Up

## Product principles
- Mobile-first participant experience.
- No participant account required for MVP.
- Minimum necessary personal information.
- One global participant profile.
- Institution affiliation does not restrict attendance.
- Host access is scoped by event host organization.
- Actionable dashboard over decorative analytics.
- Copy-and-paste communication before automation.
- Preserve history; archive rather than casually delete.
- Prefer clear, testable rules over excessive configurability.

## Success condition
The coach can operate every event without a parallel spreadsheet.

## Suggested success measures
- Registration completion rate.
- Duplicate registration rate.
- Check-in completion rate.
- Percentage of events with finalized attendance.
- Overdue follow-up count.
- Time required to prepare a roster and finish check-in.
